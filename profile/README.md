# ОКБ «Техноскан-Инжиниринг 66»

> Разработка систем непрерывного промышленного мониторинга, IIoT-решений и прикладных ML/CV-алгоритмов для производственных предприятий.

Мы объединяем аппаратную телеметрию с современным программным стеком: снимаем «сырые» данные с оборудования через безопасный гальванически развязанный контур, обрабатываем их на локальных или облачных серверах и выводим аналитику по загрузке, простоям и расходу ресурсов в реальном времени.

---

### 🛠 Направления разработки и решения

* **Industrial IoT & Telemetry Platform**
  * Сбор метрик с контроллеров и датчиков (станки с ЧПУ, прессы, ТПА, робототехника, компрессорные станции).
  * Развёртывание аналитических дэшбордов On-Premise / Cloud за 72 часа.
  * Детекция скрытых простоев, контроль циклов работы и холостого хода.

* **Computer Vision & Video Analytics**
  * Контроль соблюдения техники безопасности и регламентов (СИЗ, опасные зоны).
  * Оптический контроль дефектов полуфабрикатов и готовой продукции на линиях.

* **Applied Data Science & Machine Learning**
  * **ABC-module** — алгоритмическая классификация и приоритизация номенклатуры/заказов для оптимизации запасов.
  * **KMeans-module** — кластеризация многомерных данных для выявления паттернов и сегментации без ручной разметки.
  * Предиктивное обслуживание узлов оборудования на основе аномалий вибро- и термотелеметрии.

### 🏗 Архитектурные принципы

- **Безопасность контура:** Гальваническая развязка аппаратной части, отсутствие прямого вмешательства в заводские управляющие программы станков.
- **Интеграция:** Поддержка промышленных протоколов, соответствие ГОСТ Р МЭК 62264 (интеграция систем управления производством и АСУ ТП) и ГОСТ Р 71476-2024.
- **Отказоустойчивость:** Автономная работа модулей сбора данных при временной потере сети, буферизация на периферии (Edge).
